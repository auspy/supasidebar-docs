# Browser Selection

Choose which browser - or browser profile - opens your links. Pick on demand, assign per link, or use your active browser.

## Priority Order

When you click a link, SupaSidebar decides which browser to use based on this priority (highest first):

| Priority | Method | Example |
|----------|--------|---------|
| **1. Modifier-click** | `Opt`-click, right-click → Open With, `Cmd`-click action | You hold `Opt` and pick Safari - that wins over everything |
| **2. Preferred Browser** | An explicit preference on a saved link | One project link always opens in Firefox |
| **3. Air Traffic Control and the linked-space destination** | The first matching Open route, including the linked browser/profile fallback | A specific route above the linked-space default sends GitHub to Safari; other links use Chrome · Work |
| **4. Link opening behavior** | The configured saved/source browser, frontmost browser, or default browser behavior | A link opens in the browser it was saved from |
| **5. System default browser** | The fallback when no more specific destination applies | macOS chooses the browser |

In **1.3.0 and later**, choose a linked browser/profile from the space header or **Preferences → Spaces → My spaces**. It supplies the space’s default Open route. Earlier connections with automatic linked-profile opening explicitly disabled retain that choice until you change it. [Using 1.2.x?](/versions/1.2/profileSpaces)

A one-time **Open With** choice overrides the saved preference for that open. An explicit **Preferred Browser** takes precedence over automatic routes. **None** clears the per-link preference and restores automatic routing.

An already open page can be activated instead of opening a duplicate. The [Command Panel](/features/commandPanel) footer shows whether it will switch to a tab or open in a browser.

## Ways to Select a Browser

| Method | How |
|--------|-----|
| Right-click link | Right-click link → **Open With** → choose browser or profile |
| Right-click folder | Right-click folder → **Open All With** → choose browser for all links |
| `Opt` click | Hold `Opt` and click a link |
| `Opt Return` | Select link in Command Panel, press `Opt Return` |
| Space connection | Click the link icon next to the space name to set its default browser/profile and Live Tabs scope |
| Air Traffic Control | Set URL-based routing rules in **Preferences → Air Traffic Control**. See [Air Traffic Control](/features/airTrafficControl) |

The Command Panel ranks browser and profile choices by use. Check the displayed destination and number before selecting.

## Browser Profiles

The **Open With** menu shows individual browser profiles when a browser has two or more profiles set up. For example, if Chrome has "Work" and "Personal" profiles, both appear as separate options under Chrome in the picker.

**Where profiles appear:**
- Right-click context menu (as a submenu under each browser)
- `Opt`-click popover (as indented rows under each browser)
- Command Panel browser selection (`Opt Return`)

**How profiles are discovered:**
- Profiles are automatically detected from installed browsers (Chrome, Brave, Edge, Safari, Firefox, and more)
- Discovery runs in the background shortly after app launch
- Results are cached, so profiles appear instantly on subsequent opens
- To manually refresh, search "Refresh Browser Profiles" in the Command Panel

**Supported browsers:**
- **Chromium-based** (Chrome, Brave, Edge, Vivaldi, etc.) - reads profile directories
- **Safari** - reads profiles from the File menu (Safari must have been running at least once)
- **Firefox** - reads profiles from profiles.ini

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Opt` click | Show browser and profile picker |
| `Opt Return` | Show browser and profile picker (Command Panel) |
| `↑` `↓` | Navigate picker |
| `Return` | Select browser or profile |
| `1` through `9` | Choose a numbered destination in the Command Panel picker |
| `Escape` | Cancel |

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Browser not in picker | Only installed browsers are shown. Install in Applications folder and restart the app |
| Profiles not showing | Profiles appear when a browser has 2+ profiles. Search "Refresh Browser Profiles" in the Command Panel to re-scan |
| Safari profiles missing | Safari must have been running at least once for profile discovery. Open Safari, then refresh profiles |
| Wrong browser opens | Right-click link → Preferred Browser → choose correct one |
| Picker doesn't appear | Hold `Opt` while clicking/pressing Return |
| Assignment not saving | Use "Preferred Browser" (right-click), not one-time `Opt` click |
