# Search settings

Find a preference without remembering which section contains it.

1. Open **Preferences**.
2. Click the search field, or press `Cmd F`.
3. Type a setting or feature name, such as Command Panel, shortcuts, or route suggestions.
4. Select a result to jump to the matching setting. Results with a switch can be changed directly in the search results.

Use the arrow keys to select a result and `Return` to activate it. Press `Escape` to clear the search and return to the normal Preferences sections.

You can also find settings from the [Command Panel](/features/commandPanel) in **All** results or the **Settings** scope. Search for a setting, such as “Private Mode”, “Permission Status”, or “learning tips”, and open the result to go straight to it.

## Find space and profile settings in 1.3.0

Search for **linked browser**, **profile**, **bookmarks**, **switching spaces**, or **close tabs** to find the relevant controls. The main locations are:

- **Preferences → Spaces → My spaces** for each space's connection.
- **Preferences → Spaces → Switching spaces** for browser/profile switching.
- **Switching spaces → Advanced** for legacy tab closing and restoring.
- **Preferences → Browser Activity** for how Live Tabs and Recents appear.

For the current space, the **link icon beside its name** opens connection and bookmark actions directly. [Using 1.2.x?](/versions/1.2/profileSpaces)
