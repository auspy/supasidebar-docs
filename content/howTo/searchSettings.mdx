# Search settings

Find a preference without remembering which section contains it.

1. Open **Preferences**.
2. Click the search field, or press `Cmd F`.
3. Type a setting or feature name, such as Command Panel, shortcuts, or route suggestions.
4. Select a result to jump to the matching setting. Results with a switch can be changed directly in the search results.

Use the arrow keys to select a result and `Return` to activate it. Press `Escape` to clear the search and return to the normal Preferences sections.

You can also find settings from the [Command Panel](/features/commandPanel) using its Settings scope.
