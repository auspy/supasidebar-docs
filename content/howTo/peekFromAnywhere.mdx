# How to open SupaView from anywhere

Look something up without leaving what you're working on. [SupaView](/features/linkPreview) is SupaSidebar's small floating browser that opens on top of your current windows and leaves your browser tabs alone.

## Ways to open SupaView

| From | How | Setup |
|------|-----|-------|
| **Sidebar** | `Cmd` click a link | None |
| **Command Panel** | `Cmd Return` or `Shift Return` on a result | [Pick the key](#open-command-panel-results-in-supaview) |
| **Raycast** | Type `Peek`, then your search | [One Quicklink](#set-up-raycast) |
| **Alfred** | Type `peek`, then your search | [One custom search](#set-up-alfred) |
| **Spotlight** | Run the Peek shortcut, then type your search | [One shortcut](#set-up-spotlight) |
| **Terminal and other apps** | Open a `supasidebar://peek` link | [Link format](#supaview-links) |
| **Slack, Mail and other apps** | Click any link | [Make SupaSidebar your default browser](/features/linkPreview#open-links-from-other-apps) |

## Open Command Panel results in SupaView

Select a result in the [Command Panel](/features/commandPanel) and press the SupaView key. Saved links, recent links, live tabs, suggestions and the search row all open their page in SupaView. Results that aren't web pages, like apps, files and commands, open the normal way.

One key opens SupaView and the other searches the web with your query.

| Key | New installs | Updated from an earlier version |
|-----|--------------|---------------------------------|
| `Cmd Return` | SupaView | Web search |
| `Shift Return` | Web search | SupaView |

To swap them, open **Preferences → Command Panel → Shortcuts** and set **`Cmd Return` opens** to **SupaView** or **Web Search**. **Preferences → Shortcuts → Command Panel** shows the key each one uses right now.

## SupaView links

Any app that can open a link can send a page or a search to SupaView. The links start with `supasidebar://peek`, the name SupaView had before.

| Link | Opens |
|------|-------|
| `supasidebar://peek?q=swift%20concurrency` | Search results for the text, from the engine set in **Preferences → Command Panel → Link Opening → Search Engine** |
| `supasidebar://peek?url=https://example.com` | That page |

- **Encode spaces** as `%20` or `+`. Raycast, Alfred and the Shortcuts app do this for you.
- **Put `q=` or `url=` first.** Everything after it counts as the search or the page link, so a pasted link keeps its own `&` parts.
- **Only `http` and `https` pages open.** Other links, like files or app links, are ignored.
- **SupaSidebar doesn't need to be running.** The link starts it, and SupaView opens once it's ready.

## Set up Raycast

1. Open Raycast and run **Create Quicklink**.
2. Set **Name** to `Peek`.
3. Set **Link** to `supasidebar://peek?q={argument name="Query"}`.
4. Save the Quicklink.

To use it, type `Peek` in Raycast, press `Tab`, type your search and press `Return`.

To open a link you copied, make a second Quicklink with the link `supasidebar://peek?url={clipboard}`.

## Set up Alfred

1. Open **Alfred Preferences → Features → Web Search** and click **Add Custom Search**.
2. Set **Search URL** to `supasidebar://peek?q={query}`.
3. Set **Title** to `Peek {query}` and **Keyword** to `peek`.
4. Click **Save**.

To use it, type `peek`, a space and your search in Alfred, then press `Return`.

## Set up Spotlight

Spotlight can't pass what you type into a link, so a small shortcut named Peek asks for your search and sends it. You make it once in the Shortcuts app.

1. Open **Shortcuts** and press `Cmd N`. Name the new shortcut `Peek`.
2. Add the **Ask for Input** action and set its prompt to `Peek at`.
3. Add **URL Encode**. It encodes **Provided Input** automatically.
4. Add **URL**. Type `supasidebar://peek?q=`, then insert the **URL Encoded Text** variable right after it.
5. Add **Open URLs** and close the editor.

To use it, press `Cmd Space`, type `Peek` and press `Return`. Type your search in the box and press `Return`.

<Callout type="info">
Type only `Peek` in Spotlight before pressing `Return`. Typing your search into Spotlight runs a regular Spotlight search instead of the shortcut.
</Callout>

## Open SupaView from Terminal and scripts

```bash
open "supasidebar://peek?q=swift%20concurrency"
```

```bash
open "supasidebar://peek?url=https://developer.apple.com/documentation/swiftui"
```

## Troubleshooting

| Issue | Solution |
|-------|----------|
| `Cmd Return` searches the web instead of opening SupaView | Your Mac kept the earlier key. Press `Shift Return`, or change **`Cmd Return` opens** in **Preferences → Command Panel → Shortcuts** |
| Nothing opens from Spotlight | Type only `Peek`, press `Return`, then type your search in the box |
| The shortcut runs but SupaView stays closed | Check that the **URL** action has the **URL Encoded Text** variable right after `q=` |
| A link opens an older copy of SupaSidebar | macOS sends links to one copy when several are on your Mac. Delete old copies and keep the one in **Applications** |
| A page link does nothing | SupaView opens only `http` and `https` pages |
