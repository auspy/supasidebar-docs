# Smart Shortcuts

Context-aware shortcuts that adapt to your active application.

![Smart Save](/assets/smart%20save.jpeg)

## Overview

| Shortcut | Browser | Finder |
|----------|---------|--------|
| `Cmd Ctrl S` | Save current page | Add selected items |
| `Cmd Ctrl C` | Copy page URL | Copy file paths |

## Smart Save (`Cmd Ctrl S`)

### In Browser
1. Navigate to a page you want to save
2. Press `Cmd Ctrl S`
3. Page title and URL are saved to your sidebar

### In Finder
1. Select one or more files/folders
2. Press `Cmd Ctrl S`
3. Items are added to your sidebar

## Smart Copy (`Cmd Ctrl C`)

### In Browser
1. Navigate to the page you want to share
2. Press `Cmd Ctrl C`
3. URL is copied to clipboard, ready to paste

### In Finder
1. Select one or more files/folders
2. Press `Cmd Ctrl C`
3. File paths are copied (one per line for multiple items)

## In Other Apps

Smart Save and Smart Copy only work while a browser or Finder is the active app. Every other app keeps `Cmd Ctrl S` and `Cmd Ctrl C` for its own shortcuts, so nothing clashes.

This is the **Only in Browsers and Finder** switch at the top of **Preferences → Shortcuts → Browser and Finder Integration**. It also covers **Save All Browser Tabs** and **Open Tab in Other Browser**, which only work while a browser is active, and **Add Current Folder**, which only works while Finder is active. It's on by default. Turn it off there if you want these keys taken in every app.

The tab back and forward shortcuts are listed under **Tab Navigation** and work in any app.

## Supported Browsers

Safari, Chrome, Firefox, Edge, Arc, Brave, Vivaldi, Comet, Orion, Atlas, Zen, Wavebox, Dia, and Helium.

## Permissions

Smart Shortcuts require Automation permissions. Grant access in **System Settings → Privacy & Security → Automation → SupaSidebar**.
