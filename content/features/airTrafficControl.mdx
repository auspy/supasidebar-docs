# Air Traffic Control

Create save routes to file links into spaces, and open routes to control which browser opens them - like mail rules for your bookmarks.

## How It Works

Air Traffic Control has two types of routes:

- **Save Routes**  - When you save a page (`⌘⌃S`), save routes are checked. The first matching route files the link into the specified space. Save routes can also filter by which browser you're saving from.
- **Open Routes**  - When you click a link in the sidebar or Command Panel, open routes are checked. The first matching route opens it in the specified browser instead of your default. While SupaSidebar is your default browser, links you click in other apps, like Slack or Mail, are checked too. See [Links from other apps](#links-from-other-apps).

Rules are evaluated top-to-bottom. The **first matching rule wins**. If no rules match, the link uses your current space and default browser.

> An explicit per-link **Preferred Browser** overrides ATC. ATC rules take priority over the source browser recorded when a link was saved and the default browser. One-time browser choices (`Opt`-click, right-click → Open With) take priority over ATC. See [Browser Selection Priority](/howTo/browserSelection#priority-order) for the full order.

## Setup

1. Open **Preferences → Browsers → Air Traffic Control**
2. Toggle **Enable Air Traffic Control**
3. Click **Add Route** to create your first rule

The page starts with **Default Browser**, where links go when no route takes them. In SupaSidebar 1.7.0 and later, **SupaSidebar Default Browser** lives here instead of in **Preferences → General**.

## Creating a Rule

When you click **Add Route**, you first choose the route type:

### Save Route

Routes saved links to a specific space, and optionally a specific folder inside that space.

| Setting | Description |
|---------|-------------|
| **Source Browser** | Only match when saving from this browser, or "Any Browser" (optional). You can narrow to a specific browser profile, so saves from Chrome Work and Chrome Personal can route to different spaces |
| **URL Pattern** | Optional. Leave empty to match all URLs, including with "Any Browser" selected |
| **Match Type** | **Contains**, **Is Equal To**, **Domain** or **Matches Regex**. See [URL pattern types](#url-pattern-types) |
| **Save to Space** | The space to file matching links into |
| **Save to Folder** | Optional. A folder inside the chosen space. Matching saves land directly in this folder instead of at the space root |

### Open Route

Opens matching links in a specific browser, or in a specific browser profile. Every condition you set must match.

| Setting | Description |
|---------|-------------|
| **Clicked in** | Optional. Only match links clicked in these apps, like Slack, Mail or Ghostty. Leave it empty to match links from any app. See [Links from other apps](#links-from-other-apps) |
| **Only while this Space is active** | Optional, formerly Source Space. **Any Space** matches in every space. Pick a space to match only while it's open in the sidebar |
| **URL Pattern** | Optional when an app or a space is set. Leave it empty to match every URL |
| **Match Type** | **Contains**, **Is Equal To**, **Domain** or **Matches Regex**. See [URL pattern types](#url-pattern-types) |
| **Open in Browser** | The browser to open matching links in. You can also pick a specific profile (e.g. Chrome Work, Safari Personal) so matching links always open in the right session |
| **Skip SupaView** | Shown while [SupaView](/features/linkPreview) is on in Labs. A click on a matching link from another app opens this browser right away. See [Skip SupaView](#skip-supaview) |

A live preview at the bottom of the editor says in one sentence what the rule will do, naming its apps, its pattern, its space and the browser it opens.

An empty URL pattern means **All URLs** for every match type. Any selected app, source browser or space still limits the rule. Put an all-URLs rule below more specific rules when you want it to act as a fallback.

An Open route needs at least one condition, an app, a space or a URL pattern. Without one it won't run, its row shows **Needs a condition**, and the editor won't save it. To open every link in one browser, set **SupaSidebar Default Browser** in **Preferences → Browsers → Air Traffic Control → Default Browser** instead.

A rule whose space was deleted shows **Missing space**. Choose another space, or **Any Space**, before you save it. Importing a rule whose space can't be found keeps that limit and turns the rule off.

## URL pattern types

| Match type | Matches | Example |
|------------|---------|---------|
| **Contains** | The pattern anywhere in the URL | `github.com` matches every GitHub link, and also `notgithub.com` |
| **Is Equal To** | The whole URL, exactly | `https://mail.google.com/` matches only that page |
| **Domain** | The site and all its subdomains | `atlassian.net` matches `acme.atlassian.net`, but not `atlassian.net.example.com` or `notatlassian.net` |
| **Matches Regex** | A regular expression, anywhere in the full URL, ignoring case | `^https://(www\.)?figma\.com/(file\|design)/` matches Figma files only |

For **Domain**, you can paste a whole link. SupaSidebar keeps the domain and drops the `https://`, a leading `www.`, the path and the port.

**Matches Regex** checks the pattern as you type. A pattern that doesn't work shows the reason under the field and can't be saved. A rule that ends up with a broken pattern, for example from an import, shows **Invalid pattern** and never runs.

## Links from other apps

**Clicked in** makes a route for links you click in one app. A Jira link from Slack can open in Chrome Work while the same link from Mail opens somewhere else.

1. Open **Preferences > Labs**, turn on **SupaView**, and make SupaSidebar your default browser. See [Open links from other apps](/features/linkPreview#open-links-from-other-apps).
2. In an Open route, click **Add app** next to **Clicked in**.
3. Pick an app under **Sent links recently**, or **Choose app…** to pick any app in Applications. **SupaSidebar itself** matches links you open from the sidebar, the Command Panel and MCP.

An app alone is enough. A route with only **Clicked in** set opens every link from that app in its browser.

SupaSidebar only sees links from other apps while it's your default browser. Until then, app routes don't run, their rows show **Not default browser**, and the editor shows a note with **Open SupaView Settings**. An app you removed from your Mac stays on the route and shows **Not installed**.

## Skip SupaView

With SupaView on, a plain click on a link from another app opens SupaView. **Skip SupaView** on a route sends that click straight to the route's browser instead. `Cmd Option` click still opens SupaView.

It turns on by itself when you add an app to **Clicked in**, until you change it. URL-only routes start with it off.

What a click on a link in Slack does, with **Click Opens** set to **SupaView**

| Route that matches the link | Click or `Cmd` click | `Cmd Option` click |
|-----------------------------|----------------------|--------------------|
| No route matches | SupaView | Your SupaSidebar Default Browser |
| `youtube.com` → Chrome Personal, Skip SupaView off | SupaView | Chrome Personal |
| Slack and `atlassian.net` → Chrome Work, Skip SupaView on | Chrome Work | SupaView |
| Any route, with **Click Opens** set to **Browser** | The route's browser | SupaView |

Terminals and editors that only open links on `Cmd` click, like Ghostty, Terminal, iTerm and VS Code, count as a plain click.

The first time a route skips SupaView, a notice says where the link opened and which route sent it there, with a reminder that `Cmd Option` click previews it in SupaView. It shows once per route. Route rows show **Skips SupaView** next to the browser.

## Test a link

**Test a link** sits under the Air Traffic Control settings. Paste a link and pick the app it came from in **Clicked in**, or leave **Any app**. The answer says which route wins and where a click and a `Cmd Option` click open, and the winning route lights up in the list below.

The test uses the space that's active in the sidebar, as real clicks do. The line under the field says which one, like "Testing while Work is active". When no route matches, the answer names the browser the link falls back to. While Air Traffic Control is off, it says so and offers **Turn On**.

## Smart Suggestions

Air Traffic Control watches what you open from the sidebar and suggests new rules based on patterns it sees, so you don't have to invent every rule from scratch.

- **From the Command Panel** - When the URL you're about to open matches a strong pattern (e.g. you've opened the same domain in the same browser repeatedly), the Command Panel offers a one-click row to create the rule and open the link in the suggested browser at the same time.
- **From Preferences** - Open **Preferences - Browsers - Air Traffic Control** to see suggestions based on your recent open history. Click a suggestion to convert it into a regular rule that you can then edit or reorder like any other.

Suggestions stay out of the way until they're confident. You can ignore them and your existing rules keep working unchanged.

## Managing Rules

Each Open route's row shows the apps it's for, a **Domain** or **Regex** tag, its space or **Any Space**, and the browser it opens. A route that can't run shows why, as **Needs a condition**, **Invalid pattern**, **Not default browser** or **Missing space**. Hover the tag for the fix.

- **Reorder**  - Drag rules to change priority (first match wins)
- **Enable/Disable**  - Toggle individual rules without deleting them
- **Edit**  - Click a rule to modify its settings
- **Delete**  - Remove rules you no longer need

## Per-space default browser

In **1.3.0 and later**, the quickest way to give a space a default destination is to [link a browser or profile](/features/profileSpaces) using the icon beside its name. You can also manage it in **Preferences → Spaces → My spaces**.

The connection supplies a default Open route. It also scopes Live Tabs to that browser/profile, even though Live Tabs does not have to be visible for routing to work. A connection with the earlier automatic-opening setting explicitly turned off retains that choice until you enable it for that space.

Turning off Air Traffic Control or disabling the linked-space Open route stops that route from choosing a destination. The connection and its tab filter remain.

If you only want to change where links open, keep using a per-space Open route in **Preferences → Browsers → Air Traffic Control**. That route does not need to change which Live Tabs appear.

For links without an explicit **Preferred Browser**, Open routes are checked in their displayed order. A matching route above the linked-space default takes priority. A one-time **Open With** choice overrides both. See [Browser Selection](/howTo/browserSelection#priority-order) for the full order.

## Per-link Preferred Browser

Right-click a saved web link and choose **Preferred Browser** to set its default browser. Choose **None** to clear the preference and use automatic routing again.

Use this when one particular link should open differently from every other URL on the same domain. For example, a single Figma file in your Design space that should always open in Arc, while every other Figma link uses your default.

**When to use which:**

| Situation | Use |
|-----------|-----|
| Many URLs follow the same pattern (e.g. all `github.com`) | ATC Open Route |
| One specific saved link needs a different browser | Per-link Preferred Browser |
| A space should show one browser/profile’s tabs and open links there | Link a browser or profile |
| Only change where a space’s links open | Per-space Open route |

An explicit per-link Preferred Browser takes precedence over ATC. If both apply to the same URL, the saved link preference wins. See [Browser Selection Priority](/howTo/browserSelection#priority-order) for the full order.

## Route suggestions

SupaSidebar can suggest routes based on how you open links. Turn **Show Route Suggestions** on or off in **Preferences → Browsers → Air Traffic Control**. This controls suggestions in Preferences, the Command Panel, and browser pickers; turning suggestions off leaves your existing rules in place.

## Examples

### Save Routes

| Source Browser | URL Pattern | Save to Space | Save to Folder | Effect |
|---------------|------------|---------------|----------------|--------|
| Any | `github.com` | Development | *(none)* | All GitHub links go to Dev space root |
| Firefox | *(empty)* | Work | *(none)* | All tabs saved from Firefox go to Work space |
| Safari | `banking.` | Finance | Statements | Banking URLs from Safari land in Finance - Statements |
| Any | `docs.google.com` | Work | Docs | Google Docs go to Work - Docs |

### Open Routes

| Clicked in | URL Pattern | Open in Browser | Effect |
|------------|-------------|-----------------|--------|
| *(any app)* | `figma.com` | Chrome | Figma links always open in Chrome |
| *(any app)* | `localhost` | Safari | Local dev URLs open in Safari |
| Slack | Domain `atlassian.net` | Chrome Work | Jira links from Slack open in your Work profile, skipping SupaView |
| Ghostty | *(empty)* | Safari | Every link you click in Ghostty opens in Safari |
| *(any app)* | Regex `^https://(www\.)?figma\.com/(file\|design)/` | Chrome | Figma files open in Chrome, other Figma pages don't |

### Combining Both

Want GitHub links to go to your Dev space **and** always open in Chrome? Create two rules:

1. **Save Route**: `github.com` → Development space
2. **Open Route**: `github.com` → Chrome

Each rule does one thing clearly  - no ambiguity.

## Tips

- **Start broad, refine later**  - Begin with domain-level patterns like `github.com`, then add specific patterns if needed
- **Use Domain for a whole site**  - `atlassian.net` covers every subdomain without matching look-alike sites
- **Test before you trust it**  - Paste a link into **Test a link** to see which route wins
- **Order matters**  - Put more specific rules above general ones
- **Source browser filters are powerful**  - Use them to keep different browsers organized into separate spaces automatically
- **Combine with Spaces**  - ATC is most useful when you have multiple spaces for different contexts
