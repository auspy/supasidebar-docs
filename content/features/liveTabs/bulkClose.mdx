# Bulk Closing Tabs

Right-click any live tab to close a whole window's worth of tabs, a whole browser's worth, or everything above or below that tab, without closing them one at a time.

## Right-click Actions

Right-click a tab in the Live Tabs list to see these bulk-close actions alongside the regular per-tab actions (Activate, Open With, Close Tab):

| Action | What it does |
|--------|--------------|
| **Close Other Tabs in Window** | Closes every other tab in the same browser window, leaving only the one you clicked |
| **Close Other Tabs in Browser** | Closes every other tab in that browser across all its windows, leaving only the one you clicked |
| **Close Other Tabs in All Browsers** | Closes every other tab across every browser, leaving only the one you clicked |
| **Close All Tabs in Browser** | Closes every tab in that browser, including the one you clicked |
| **Close Tabs Above (in Window)** | Closes every tab above this one in the same window |
| **Close Tabs Below (in Window)** | Closes every tab below this one in the same window |

Above/Below are scoped to the tab strip of the same browser window - they don't reach into other windows or other browsers.

## Other Tabs vs All Tabs

**Close Other Tabs in Browser** keeps the tab you right-clicked open. **Close All Tabs in Browser** closes it too. Use Other Tabs to clean up around the page you're on; use All Tabs when you're done with that browser entirely.

## Tips

- Works in both expanded mode and compact mode.
- Bulk-closing tabs works the same across every supported browser - see [Live Tabs](/features/liveTabs) for the full compatibility list.
- See [Live Tabs](/features/liveTabs) for the rest of the right-click actions, including Open With, Move to Browser, and Save Tab.
