# Link Notes

Attach a short note to any saved link to remember why you saved it.

A note is free-form text tied to one link - up to 200 characters. Use it to jot down why a link matters, what you were meant to do with it, or context you'd otherwise forget by the time you come back to it.

## Add or Edit a Note

- **From the sidebar** - Right-click a link and choose **Add Note** (or **Edit Note** if it already has one)
- **From the Command Panel** - Select a link and press `Opt Return` to open the actions panel, then choose **Add note**

Type your note and press `Cmd Return` to save, or click **Cancel** to discard changes. A character counter shows how close you are to the 200-character limit.

## Visible on the Link

Links with a note show a small note icon. Hover the link and click the icon to edit the note without opening the right-click menu.

## Searchable

Command Panel search matches your note text, not just the link's name and URL. Matching notes appear as a highlighted snippet in the result, so a link you can't remember the name of is still findable by why you saved it.

## Tips

- Notes are capped at 200 characters - keep them short and specific.
- Saving an empty note clears it from the link.
- See [Command Panel](/features/commandPanel) for the full actions panel and search behavior.
