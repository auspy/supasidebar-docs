# Search Shortcuts

Choose a website scope to find its open tabs, saved links, and recent pages, or search that website for something new.

## Choose a website

1. Open the [Command Panel](/features/commandPanel) with `Cmd Ctrl K`.
2. Click a website icon in the scope bar, or type `/` to open the scope picker.
3. In the picker, type part of the site's name or keyword, such as `gh` for GitHub or `yo` for YouTube.
4. Press `Space` or `Return` to select it.

Selecting a website keeps your existing query. With an empty query, you can browse matching live tabs, saved pages, and recent visits from that site. Type to narrow the results, or choose the website search action to search online.

Clearing the query keeps the website selected. Click **All** to leave it, or use `Tab` and `Shift Tab` to switch scopes. Pressing `Escape` while the scope picker is open restores your previous search.

## Search any website scope

The same browsing and search behavior applies across website scopes, including your own shortcuts. YouTube is one example, not a separate search mode. The picker accepts partial website names or keywords, so you do not need to remember an exact trigger.

## Add Your Own

1. Open **Preferences - Command Panel**
2. Under **Website Search Shortcuts**, click **Add Shortcut**
3. Fill in:
   - **Keyword** - the short trigger you'll type (no spaces)
   - **Website Name** - the display name shown for the website scope
   - **Search URL** - the site's search URL with the query parameter left dangling (e.g. `https://www.youtube.com/results?search_query=`)
4. Click **Save**

Your query is appended to the Search URL automatically, so the URL should end right where the search term belongs.

Edit, delete, or drag to reorder shortcuts in the same **Website Search Shortcuts** list. Their order carries through to the scope bar.

## Tips

- Keywords can't contain spaces and must be unique across your shortcuts.
- Search URLs must start with `http://` or `https://`.
- See [Command Panel](/features/commandPanel) for the rest of the search and navigation features.
