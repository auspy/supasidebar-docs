# Dock Mode

Browser maximizes to full screen when the sidebar closes.

## How It Works

{/* ![Dock Mode](/assets/browser-integration/dock.jpeg) */}

The sidebar acts like a dock - when visible, it takes its space. When hidden, your browser automatically maximizes to use the full screen.

## Setup

1. Open **Preferences → Sidebar → Browser Integration**
2. Set **Sidebar Browser Integration** to **Independent**
3. Set **When Sidebar Opens** to **Maximize Browser Window**
4. Set **When Sidebar Hides** to **Expand Browser to Fill Screen**
5. Grant [Accessibility permission](/gettingStarted/permissions#accessibility) when prompted

Dock Mode is this combination of settings, rather than a separate **Dock** option. See the [Dock Mode guide](/features/sidebarAccess/dockmode) for settings and troubleshooting.

## When to Use

- You want full-screen browsing when sidebar is hidden
- You frequently switch between sidebar and full browser
- You prefer automatic maximize behavior
