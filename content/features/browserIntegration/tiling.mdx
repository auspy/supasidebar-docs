# Window Tiling

Automatically arrange browser windows as equal-width columns alongside the sidebar.

## Overview

Window Tiling turns your screen into an organized workspace. When you open the sidebar, SupaSidebar arranges up to 4 browser windows on that screen as equal-width columns in the remaining space. The sidebar docks at the screen edge, and the browser windows fill the rest. No manual dragging or resizing needed.

## Setup

1. Open **Preferences → Sidebar → Browser Integration**
2. Set **When Sidebar Opens** to **Auto-Tile Browser Windows (max 4)**
3. Choose what should happen under **When Sidebar Hides**. See [When the Sidebar Hides](#when-the-sidebar-hides)
4. Grant [Accessibility permission](/gettingStarted/permissions#accessibility) when prompted

Tiling works with both **Smart Attach** and **Independent** integration. If **Draggable Sidebar** is on and you have moved the sidebar away from the screen edge, tiling is skipped, because the columns need the sidebar at the edge.

To switch tiling on and off without opening Preferences, record a shortcut for **Toggle Auto-Tile on Open** in **Preferences → Shortcuts**. It has no default shortcut.

Older versions had separate **Smart** and **All Windows** tiling modes. Both were replaced by the single **Auto-Tile Browser Windows (max 4)** option, which tiles every eligible browser window on the screen.

## How the Layout Works

The sidebar docks to the screen edge (left or right, based on your preference). The remaining width is divided equally among the browser windows. Windows keep their left-to-right order, so the window that was on the left stays on the left.

A window counts as on the screen when at least 20% of it is on that display.

### With 2 Windows

The screen splits into three sections.

```
┌──────────┬──────────────────┬──────────────────┐
│          │                  │                  │
│ Sidebar  │   Browser 1      │   Browser 2      │
│          │                  │                  │
│          │                  │                  │
└──────────┴──────────────────┴──────────────────┘
```

Each browser window gets half of the remaining space.

### With 3 Windows

```
┌──────────┬────────────┬────────────┬────────────┐
│          │            │            │            │
│ Sidebar  │ Browser 1  │ Browser 2  │ Browser 3  │
│          │            │            │            │
│          │            │            │            │
└──────────┴────────────┴────────────┴────────────┘
```

Each browser window gets one-third of the remaining space.

### With 4 Windows

```
┌──────────┬─────────┬─────────┬─────────┬─────────┐
│          │         │         │         │         │
│ Sidebar  │Browser 1│Browser 2│Browser 3│Browser 4│
│          │         │         │         │         │
│          │         │         │         │         │
└──────────┴─────────┴─────────┴─────────┴─────────┘
```

Each browser window gets one-quarter of the remaining space. Four columns need a wide screen, see [Screen Width Limit](#screen-width-limit).

### With 1 Window

The single browser window resizes to fill all the space beside the sidebar, the same result as [Fill Screen](/features/browserIntegration/fillScreen).

### With 5 or More Windows

SupaSidebar tiles 4 of them. Windows from the browser you are using come first. The other windows stay where they are.

### Screen Width Limit

Each column needs at least 500px. On a narrower screen, SupaSidebar tiles fewer windows so every column stays usable. The table below assumes the default sidebar width.

| Screen width | Columns |
|--------------|---------|
| About 1,500px (most MacBooks) | **2** |
| 1,920px | **3** |
| 2,560px or wider | **4** |

A wider sidebar leaves less room, so you may get one column fewer.

## When Tiling Activates

Tiling runs when you open the sidebar in one of these ways.

- **Keyboard shortcut** - press your configured sidebar shortcut
- **Menu bar icon** - click the SupaSidebar icon in the menu bar
- **Floating button** - click the floating sidebar button
- **Auto-show** - switch from a non-browser app to a browser window, and the sidebar appears with windows already tiled
- **Switching Spaces** - when the sidebar comes with you to another Space, the browser windows there are tiled

Tiling does not run in two cases.

- **A mouse trigger opens the sidebar** - hovering the screen edge never rearranges your windows
- **You are in a full-screen or Split View space** - macOS controls that layout

Tiling happens once, when the sidebar opens. Switching browsers, changing focus or opening a new window while the sidebar is open does not re-tile.

### What Happens Step by Step

1. You open the sidebar
2. SupaSidebar finds the browser windows on the current screen
3. The sidebar moves to the screen edge
4. Up to 4 browser windows are resized and positioned as equal columns
5. All tiled windows are brought to the front so they're visible

Most browsers snap into place instantly. Firefox and Zen settle into their new size over about a second. See [Browser Integration](/features/browserIntegration) for why.

## While Tiling Is Active

Once windows are tiled, the layout stays stable.

- **Switching focus between tiled windows** - click any tiled window and it comes to focus. The layout doesn't change, and windows stay in their positions.
- **The sidebar stays docked** - it remains at the screen edge rather than following a specific browser window.

## When Tiling Breaks

- **Drag a tiled window** - if you move a tiled window, the tiling layout ends. The sidebar switches back to normal attach behavior and follows the window you're using.
- **Close the sidebar** - what happens next depends on **When Sidebar Hides**. See below.

To re-tile, simply open the sidebar again.

## When the Sidebar Hides

Set this in **Preferences → Sidebar → Browser Integration → When Sidebar Hides**. Each option treats tiled windows differently.

| Option | Tiled windows when the sidebar hides |
|--------|--------------------------------------|
| **Restore Browser Position** (default) | Return to their size and position from before tiling |
| **Expand Browser to Fill Screen** | Re-tile across the full screen width |
| **Leave Browser As-Is** | Stay in their tiled columns |

See [Sidebar Panel - Behavior](/features/sidebar#behavior) for details.

## Browser Profiles

Tiling includes every eligible browser window on the screen, from any browser or profile. Spaces linked to [Browser Profiles](/features/profileSpaces) do not limit which windows are tiled.

### Close Tabs on Space Change

If you have **Close and reopen tabs on space change** enabled (in **Preferences → Spaces → Switching spaces → Advanced**), the outgoing profile's browser windows are closed when you switch spaces. When you switch back, the browser re-launches with a single window, so you get one full-width window instead of columns.

To keep several windows tiled while switching profile spaces, keep this setting off. Your profile windows stay open in the background and tile when you return to that space.

## Tips

- **Best on wide screens** - tiling shines on large or ultrawide monitors where there's enough space for the sidebar plus three or four comfortable browser columns.
- **Use with auto-show** - if you enable auto-show (sidebar appears when you switch to a browser), your windows tile every time you switch to your browser from another app.
- **Expand on hide** - pick **Expand Browser to Fill Screen** under **When Sidebar Hides** if you want your columns to use the full screen width once the sidebar closes.
