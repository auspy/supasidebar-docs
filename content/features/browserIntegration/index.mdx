# Browser Integration

Choose how SupaSidebar interacts with your browser windows.

Configure in **Preferences → Sidebar → Browser Integration**.

## Modes

| Mode | Description |
|------|-------------|
| **Independent** | Sidebar stays at the screen edge instead of following a browser window |
| **Smart Attach** | Sidebar attaches to your browser and manages window layout |

## Smart Attach

Smart Attach is the recommended mode. When enabled, the sidebar intelligently positions itself next to your browser and adjusts windows to avoid overlap. Until an eligible browser gains focus, the sidebar stays at the screen edge. It then attaches to the browser.

Choose **Preferences → Appearance → Motion → Smart Attach Motion** to adjust how closely the sidebar follows a moving browser: **Tighter**, **Tight**, **Balanced**, or **Loose**. **Tight** is the default. These options change the trailing motion while dragging; all settle beside the browser.

Browser positioning and resizing are separate controls. Configure these in Preferences:

| Feature | Description |
|---------|-------------|
| [Fill Screen](/features/browserIntegration/fillScreen) | Choose **Maximize Browser Window** to fill the space alongside the sidebar. Works with both **Smart Attach** and **Independent** integration. |
| [Window Tiling](/features/browserIntegration/tiling) | Choose **Auto-Tile Browser Windows (max 4)** to arrange 2-4 eligible browser windows alongside the sidebar |
| [Prevent Browser Overlap](/features/browserIntegration/smart) | Automatically moves browser windows out from under the sidebar |
| Auto-Switch Side on Clipped Browser | Flips the sidebar to the opposite side when your preferred side would be cut off by an adjacent monitor |
| [When Sidebar Opens](/features/sidebar#behavior) | Choose **Off**, **Auto-Tile Browser Windows (max 4)**, or **Maximize Browser Window** |
| [When Sidebar Hides](/features/sidebar#behavior) | Choose **Restore Browser Position**, **Expand Browser to Fill Screen**, or **Leave Browser As-Is** |

## Independent

The sidebar stays at the screen edge instead of following the browser. The separate **When Sidebar Opens** and **When Sidebar Hides** settings still control browser resizing. For a browser that fills the space beside the sidebar and expands when it closes, see [Dock Mode](/features/sidebarAccess/dockmode).

## Profile-Aware Behavior

When a space is linked to a browser profile, Smart Attach automatically targets the profile's browser window. Switching spaces re-applies the integration to the new profile's browser.

See [Browser Profiles](/features/profileSpaces) for details.

## Sidebar Hide Behavior

When using Smart Attach, the sidebar's auto-hide behavior in browsers is controlled separately from general [mouse trigger](/features/sidebarAccess/mouseTriggers) settings. In non-browser apps, the sidebar automatically hides when you move your mouse away. In browsers, the sidebar may stay visible because Smart Attach is actively managing your window layout.

To configure how the sidebar hides when a browser is active, go to **Preferences → Sidebar → Sidebar Behavior** and enable the browser auto-hide setting. There may be a short delay before auto-hide activates - this prevents the sidebar from flickering during normal use.

If the sidebar isn't auto-hiding in browsers, see [Sidebar Doesn't Hide in Browser](/troubleshooting/sidebarDoesntHideInBrowser).

## Permissions

Smart Attach requires Accessibility permissions. See [Permissions Guide](/gettingStarted/permissions). If Smart Attach is on but the sidebar isn't shifting your browser windows, jump to [Reset Permissions](/troubleshooting/permissions).
