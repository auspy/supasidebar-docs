# Linked browsers and profiles troubleshooting

<Callout type="info">
These instructions apply to **SupaSidebar 1.3.0 and later**. [Using 1.2.x?](/versions/1.2/profileSpaces)
</Callout>

Start with the **browser/profile label next to the space name**. It shows what the space is linked to. Click it for connection status, bookmark checking, or **Unlink**. You can also find the connection in **Preferences → Spaces → My spaces**.

## A profile isn't showing up in the picker

1. Open the profile in its browser so the browser has created its data.
2. Use **Refresh Profiles** in the picker, then look again.
3. If an access warning appears, follow it to **Permission Status**.

Some browsers support a whole-browser connection without individual profile linking. Check the choices in the picker and [Browser Support](/gettingStarted/browserSupport). For a Chromium profile still missing after refresh, see [Missing browser profiles](/troubleshooting/browserProfilesMissing).

## Live Tabs is empty in a linked space

Check the specific condition before changing permissions:

| What you see | What to check |
|--------------|---------------|
| A different browser/profile beside the space name | Unlink it, then link the intended browser or profile |
| **Live Tabs is turned off** | Enable Live Tabs in **Preferences → Browser Activity**, or enable that browser's Live Tabs in **Privacy & Browsers**, as directed by the message |
| **Allow access to show tabs** | Use **Review permissions**, then grant the permission named in the warning |
| Browser is blocked or Live Tabs is unavailable | Review **Preferences → Privacy & Browsers** and the [browser support guide](/gettingStarted/browserSupport) |
| **No tabs to show** with no blocker | Open a window in the linked profile and open a tab; use **Open profile** or **Open browser** if offered |
| A profile-identification message | Keep the intended browser/profile window open and retry; include the exact message if contacting support |

If tabs appear in an unlinked space but not in the linked space, include that detail when reporting the issue. It helps distinguish reading browser tabs from matching them to a particular profile.

**Connected** means the space has a saved connection. It is not a claim that every browser operation has been tested. SupaSidebar does not block the normal Live Tabs loader just because a permission check has not yet been verified.

See [Permissions troubleshooting](/troubleshooting/permissions) if a required permission is denied or a browser operation fails.

## The wrong browser opens a link

1. Check for an explicit **Preferred Browser** on the saved link.
2. Check **Preferences → Air Traffic Control**. Open routes are checked in their displayed order; a matching route above the linked-space default wins.
3. Check that Air Traffic Control and the linked-space Open route are enabled.
4. Check the selected space’s connection in **Preferences → Spaces → My spaces**. An earlier choice to keep automatic linked-profile opening off is preserved after updating.

A one-time **Open With** choice overrides automatic routing. The saved link's **Preferred Browser** also takes precedence over ATC. See [Browser Selection](/howTo/browserSelection#priority-order) for the complete order.

If only one link should open elsewhere, use **Open With** or **Preferred Browser** on that link. If the entire space should use its linked browser/profile, choose **Open links in this browser or profile** in the space’s connection settings when the earlier opt-out message appears.

## Focusing a browser doesn't switch spaces

Open **Preferences → Spaces → Switching spaces → When a linked browser/profile becomes active**. Choose **Ask to switch space**, **Switch automatically**, or **Do nothing**.

The default is **Do nothing**, so choose one of the other options if you want SupaSidebar to follow the active browser/profile.

This existing behavior requires Live Tabs to be enabled. It also needs a matching linked space and an identifiable browser/profile. The setting does not add a connection to an unlinked space.

## The linked browser doesn't launch on a space change

Check **Preferences → Spaces → Switching spaces → Open linked browser if it isn’t running**. This existing behavior requires Live Tabs to be enabled.

This option is off by default.

Confirm the space is linked to the intended browser/profile and that browser is still installed. Try **Open browser** or **Open profile** from the empty Live Tabs area. If opening fails, include the browser/profile and any permission warning in your report.

## Tabs close when I switch spaces

Check **Preferences → Spaces → Switching spaces → Advanced → Close and reopen tabs on space change**. This is the legacy tab-memory feature, previously named **Link Open Tabs to Space**. It is separate from connecting a browser/profile. Its close step is browser-wide for a linked space, so tabs in another profile of that browser can also close.

Turn it off if you want to keep browser tabs open. If you keep it enabled, [lock individual tabs](/features/linkOpenTabs#locks-keep-a-tab-open-everywhere) that should remain open across spaces.

## Bookmarks are missing from the results

A named profile reads that profile's bookmarks. A whole-browser connection reads all discovered profiles supported by its importer. **Safari reads its bookmark library**, including when a named Safari profile is linked.

A warning names profiles whose bookmark files could not be found or read. This does not mean the browser is uninstalled. You can review bookmarks from the other profiles, then retry after opening the affected profile and saving a bookmark there.

Bookmark fetching is manual. Use **Check for new bookmarks in…** again after adding bookmarks in the browser. Changes made in SupaSidebar are not sent back to the browser. See [Import Bookmarks](/howTo/browserImport) for an HTML import fallback.

## Change or remove the connection

Click the linked browser/profile beside the space name and choose **Unlink**. To replace it, click the link icon and select the new browser/profile. Bookmarks already added to the space remain saved.
